# Exact versions the test suite is green against.
#
# Every dependency in pyproject.toml is declared as a floor (>=), which is right
# for a library and wrong for a deployment: Render builds from scratch, so a
# floor means production installs whatever was released this morning rather than
# what CI proved. This file constrains, it does not install -- pyproject.toml
# stays the single declaration of *what* is needed and this file fixes only
# *which version*.
#
# Used by the CI install step and by both render.yaml buildCommands, which is
# what makes render.yaml's claim that "green in CI and runs in production mean
# the same thing" literally true rather than aspirational.
#
# Three of these are load-bearing beyond the usual:
#   anthropic  -- ai/client.py is written against a specific output_config /
#                 transform_schema / streamed-structured-output shape (T2.1).
#                 A break there is silent, expensive, and CI cannot see it: the
#                 live tests are billed and deselected by default.
#   fastapi    -- 0.140 changed how include_router stores routes internally.
#   starlette  -- not a direct dependency, so fastapi's own range lets it move
#                 underneath a pinned fastapi. Pinned here explicitly.
#
# Generated on Windows, so Linux-only wheels (uvloop, httptools) are absent.
# That is harmless: an unlisted package is simply unconstrained.
#
# Regenerate after an intentional upgrade, from a venv with the suite green:
#   python -m pip freeze --exclude-editable
